# Support

Thanks for using **bettercollected**! This page explains where to get help.
Please pick the channel that matches what you need — it helps us route things
quickly and keeps the issue tracker focused on actionable work.

## I have a question or need help

- **How do I set things up / develop locally?** Start with
  [CONTRIBUTING.md](CONTRIBUTING.md) and the
  [Developer's Guide](docs/DEVELOPERS_GUIDE.md). Most setup questions are
  answered there (the correct **uv + yarn** flow, running services, and tests).
- **How does the system fit together?** See
  [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
- **Usage / "how do I…" questions.** Open a
  [GitHub Discussion](https://github.com/bettercollected/bettercollected/discussions)
  if Discussions are enabled; otherwise open an issue using the **Question**
  option. Please don't email maintainers directly for usage questions — public
  answers help the next person with the same question.

## I found a bug

Open a [bug report](https://github.com/bettercollected/bettercollected/issues/new/choose)
and fill in the template (affected service, steps to reproduce, expected vs.
actual). Search existing issues first — it may already be tracked.

## I have a feature idea

Open a **Feature request** issue. Describe the problem you're trying to solve,
not just the solution — it helps us find the best fit. See the
[Roadmap](ROADMAP.md) for where the project is heading.

## I found a security vulnerability

**Do not open a public issue.** Follow the private disclosure process in
[SECURITY.md](SECURITY.md) (GitHub Security Advisories, or
security@bettercollected.com).

## I want to contribute

Wonderful — see [CONTRIBUTING.md](CONTRIBUTING.md). Look for issues labelled
[`good first issue`](https://github.com/bettercollected/bettercollected/labels/good%20first%20issue)
or `help wanted` to get started.

## Commercial / hosted product

For questions about the hosted product at
[bettercollected.com](https://bettercollected.com), use the contact options on
the website. This repository's issue tracker is for the open-source codebase.
