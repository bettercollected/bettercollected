- The Activity page has an Export menu: the entries of the filters on screen as a CSV or JSON file,
  with the same filters and permission as the list (Owner, Admin, Privacy officer), also for a form's
  own activity. A Privacy officer's file has no session or response ids, exactly like their screen.
  Exporting is itself recorded in the log before the file starts (nothing is sent if that cannot be
  recorded), at most 100,000 entries and five exports per person every ten minutes.
