- Saved report views: an account's private views and every view of a deleted workspace are deleted
  with them (also on a form that stays because another workspace holds it), and the deletes with a
  form, a member, an account or a workspace run whatever the switch says; a stale change or delete of
  a view leaves no audit entry; "Update view" is not offered when the report holds cards the person
  cannot see (it would drop them), only a save as a new view; a card title is no longer stored in a
  view.
- Report page: it no longer asks for the figures again when the browser tab gets the focus or
  the network comes back (a pass can read 20,000 responses); an edited card no longer draws its
  old figures under its new labels; a negative value gets no bar, and a line over time keeps
  negative values inside its plot; the numbers in "too many responses" and in the middle of a
  donut follow the viewer's locale; the sixth chart colour is defined in dark mode and the
  "Group by" select no longer runs its text into its arrow.
