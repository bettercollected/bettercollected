- The responses list no longer shows "No responses yet" or "Nothing matches" while
  it is still waiting for the server, for example right after Retry or after
  clearing a search. When the last rows of a later page are deleted, the list now
  goes back a page instead of saying the form has no responses. After Retry the
  keyboard focus stays in the list.
- Answers with several selected options now read "Reading, Cycling" in the
  responses table and the response panel, instead of "Reading,Cycling".
- The deletion requests table no longer puts the full receipt number in a tooltip.
  It shows the first 8 characters, like the response panel, and both now shorten
  numbers that have no dashes too. The search box on the deletion requests tab is
  labelled for deletion requests.
